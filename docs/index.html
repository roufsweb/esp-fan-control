Download APK
Firmware Flashed Successfully!

Next steps to start the fan:

  1. Press the RST button on your ESP32-C3 board (or unplug and re-plug USB) to start normal mode.
  2. The onboard LED will pulse (confirms active Bluetooth beacon).
  3. Open the Fan Control app — it connects automatically!

Note: Bluetooth connects directly inside the Fan Control app. Custom BLE hardware does not appear in Android system settings.

Wiring Pinout

Wire Pin Specification
Blue GPIO 4 25 kHz PWM
Yellow GPIO 3 Tachometer (Pull-up)
Red +5V / +12V Power rail
Black GND Common ground

Setup

  1. Connect ESP32-C3 via USB (hold BOOT) and tap Flash ESP32 above.
  2. Press the RST button on ESP32 (or unplug & re-plug USB) to start.
  3. Install and open the Android APK — connects automatically inside the app.
